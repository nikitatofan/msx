# Мой телевизор — тест MSX

Это меню внутри Media Station X, не прошивка и не замена ОС.

## Публикация
1. Создайте PUBLIC репозиторий nikitatofan/msx.
2. Загрузите start.json, home.json, test.mp4 и этот README.md в корень (не ZIP).
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Дождитесь успешной публикации. Проверьте https://nikitatofan.github.io/msx/start.json .
5. На ТВ: MSX → Settings → Start Parameter → Setup. Введите nikitatofan.github.io, включите HTTPS (замок), подтвердите Мой телевизор.

Вводится только nikitatofan.github.io: MSX сам добавит /msx/start.json.
Если приложение не может загрузить HTTPS, сообщите точную ошибку; не отключайте защиту сети.

## Тест
Проверить кнопки показывает сообщение. Проверить видео запускает собственный шестисекундный файл H.264 Baseline/AAC с негромким тоном 440 Гц. Back возвращает в меню. Фактическая совместимость LG ещё требует проверки.

Настройки открывает настройки MSX, не сервисное меню LG.
Не добавляйте пароли, токены и приватные ссылки: файлы публичны.
Авторизации, аналитики, внешних каталогов и сторонних фильмов здесь нет.
